# Review

Comments from the reviewer. Write one per line, under a heading for the page and section, as an open checkbox:

```markdown
## About · hero
- [ ] Option B, but make the headline shorter. (2026-10-30)
```

Claude reads this at the start of every session. When a comment is handled, it ticks the box and adds a line saying what changed:

```markdown
- [x] Option B, but make the headline shorter. (2026-10-30)
  → Done: cut the headline to five words, kept B. (2026-10-31)
```

Comments are never deleted, so this file is also the history of the review.
